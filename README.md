# ☕ JavaDesktopManagementSystems

A comprehensive portfolio collection of production-ready **Java Desktop Management Systems, Point of Sale (POS) Solutions, and Enterprise Database Applications** built with Java Swing, FlatLaf, NetBeans, Maven, and SQL.

---

## 🌟 Overview & Systems Included

| # | System / Module | Key Technologies | Description |
|---|---|---|---|
| **01** | `01-Restaurant-Management-System` | Java Swing, SQL, POS | Full-featured restaurant POS, table management, customer billing, and live order tracking. |
| **02** | `02-Hotel-Properties-System` | Java Swing, Maven, SQL | Property management system for hotel rooms, guest check-in/out, and billing. |
| **03** | `03-Pharmacy-Inventory-System` | Java Ant, Database | Medicine inventory management, expiry tracking, prescription records, and cashier sales. |
| **04** | `04-Electricity-Billing-System` | Java GUI, SQL | Electricity utility billing, subscriber accounts, meter consumption calculations, and invoices. |
| **05** | `05-Stadium-Ticketing-Booking` | Java Swing, Custom UI | Football stadium grandstand seat reservations, ticket barcode/issuing, and match scheduling. |
| **06** | `06-Pizzeria-Ordering-POS` | Java Swing, Menu POS | Pizzeria sales, custom pizza order customization, takeaway/delivery tracking. |
| **07** | `07-Car-Rental-Fleet-System` | Java Swing, Fleet Mgmt | Car rental agency booking, fleet maintenance tracking, and customer contracts. |
| **08** | `08-Bakery-Shop-Sales-System` | Java Swing, Retail POS | Bakery sales, inventory control of fresh batches, and daily accounting. |
| **09** | `09-Safety-Road-Transport-System` | Java NetBeans, Logistics | Transportation dispatching, fleet road safety records, and cargo shipments. |
| **10** | `10-School-Academic-Management` | Java Swing, Academic DB | School student registration, gradebook management, attendance, and timetable schedules. |
| **11** | `11-Food-Ordering-POS` | Java GUI, Fast Food POS | Fast food counter ordering, instant receipt printing, and kitchen order dispatch. |

---

## 🛠️ Architecture & Technologies
- **Language:** Java (JDK 8 / 11 / 17+)
- **UI Frameworks:** Java Swing, AWT, FlatLaf modern Look & Feel
- **Database Connectivity:** JDBC with MySQL / SQLite / SQL Server
- **Build Tools:** Maven & NetBeans Ant

---

## 🚀 How to Run
1. Open any desired project folder inside **NetBeans IDE**, **IntelliJ IDEA**, or **Eclipse**.
2. Make sure your local SQL database (MySQL / XAMPP) is running if the module connects to an external database.
3. Clean & Build the project and run the primary `Main.java` or `LoginForm.java`.
